# winsoftpack

Коллекция небольших программ для Windows.

## Приложения

| Приложение | Описание |
|---|---|
| [Перекур](perekur/) | Напоминание сделать перерыв в работе: сигнал в выбранное время, интервалы повтора, диапазон времени, готовые шаблоны, звуки из системы и уведомление в панели уведомлений Windows. |
