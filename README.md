# winsoftpack

Коллекция небольших программ для Windows.

## Приложения

| Приложение | Описание |
|---|---|
| [Перекур](perekur/) | Напоминание сделать перерыв в работе: сигнал каждые N минут, **каждый час в :55** (08:00–17:00) или раз в день; диапазон времени, дни недели, готовые шаблоны, звуки из системы и уведомление в панели уведомлений Windows. Есть [веб-версия](perekur/web/) (PWA, без установки, работает по двойному клику). |
