# Перекур

<p align="center">
  <img src="assets/perekur-preview.png" alt="Перекур" width="180" />
</p>

Простейшее Windows-приложение для напоминаний о перерывах в работе: **в выбранное время воспроизводит сигнал** и показывает уведомление в панели уведомлений (Action Center).

## Возможности

- 🔔 **Сигнал по расписанию** — каждые N минут внутри диапазона времени, каждый час в заданную минуту (например, в :55 с 08:00 до 17:00) **или** один раз в день в выбранное время.
- 🧩 **Готовые шаблоны** — «Каждый час», «Каждый час в :55 (08:00–17:00)», «Помодоро 25/5», «Глаза 20-20-20», «Разминка», «Обед в 13:00», «Отбой от экрана в 23:00» — один клик, и все поля заполнены.
- 🔊 **Звуки из системы** — встроенные системные звуки Windows (Asterisk, Beep, Exclamation, Hand, Question) + все `.wav` из `C:\Windows\Media` + выбор своего `.wav`-файла. Прослушивание прямо в окне.
- ⏰ **Выбор времени** — ежедневный сигнал в конкретное время (например, 13:00).
- 🔁 **Интервал повтора** — от 1 до 480 минут; сигналы привязаны к началу диапазона (09:00, 10:00, 11:00…), а не скользящие.
- 🕐 **«Каждый час в …»** — сигнал ровно в указанную минуту каждого часа внутри диапазона (например, в :55 с 08:00 до 17:00); дни недели — как обычно.
- 🌅 **Диапазон времени и дни недели** — например, 09:00–18:00, понедельник–пятница. Вне диапазона и в невыбранные дни сигнала нет.
- 🪟 **Панель уведомлений** — уведомление появляется в Action Center Windows 10/11 (через иконку в трее) и ждёт там, пока вы его не увидите.
- 📌 **Трей** — приложение живёт в области уведомлений: «Открыть», «Напоминания включены», «Перекур сейчас», «Отложить на 5 минут», «Выход».
- 🚀 **Автозапуск с Windows** — по желанию, через `HKCU\...\Run` (без прав администратора), сразу свёрнутым в трей.
- 💾 **Настройки сохраняются автоматически** в `%APPDATA%\Perekur\settings.json`.

## Веб-версия

Есть [браузерная версия](web/) — те же шаблоны и расписание, PWA, уведомления через браузер. Двойной клик по `web/index.html` — и работает.

## Требования

- Windows 10 / 11
- Для сборки из исходников: [.NET 8 SDK](https://dotnet.microsoft.com/download) (`winget install Microsoft.DotNet.SDK.8`) или Visual Studio 2022 версии 17.8+

## Сборка и запуск

### Из командной строки

```cmd
cd perekur
dotnet build -c Release
dotnet run --project src\Perekur
```

### Единый .exe (Windows x64)

```cmd
cd perekur
dotnet publish src\Perekur -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Результат: `src\Perekur\bin\Release\net8.0-windows\win-x64\publish\Perekur.exe` — можно копировать куда угодно и запускать без установки .NET.

### В Visual Studio

Откройте `Perekur.sln` → F5.

## Как это устроено

```
perekur/
├─ Perekur.sln
├─ assets/perekur-preview.png      # обложка для репозитория
└─ src/Perekur/
   ├─ Perekur.csproj               # net8.0-windows, WinForms
   ├─ Assets/perekur.ico           # иконка (встроенный ресурс)
   ├─ Program.cs                   # точка входа
   ├─ MainForm.cs                  # окно, трей, меню, обработчики
   ├─ AppSettings.cs               # модель настроек
   ├─ SettingsStore.cs             # JSON в %APPDATA%\Perekur
   ├─ Autostart.cs                 # автозагрузка (HKCU\...\Run)
   ├─ SoundCatalog.cs              # системные звуки + C:\Windows\Media + свой .wav
   ├─ BreakTemplates.cs            # готовые шаблоны
   └─ ReminderEngine.cs            # таймер, расчёт следующего сигнала
```

- **Планировщик** раз в секунду сравнивает текущее время с ближайшим запланированным сигналом. Сигналы ставятся в сетку `RangeStart + k * Interval`, поэтому расписание предсказуемо и переживает простои (после сна ПК сигнал подастся один раз).
- **Уведомление** отправляется через `NotifyIcon.ShowBalloonTip`: на Windows 10/11 оно доставляется в панель уведомлений (Action Center) и сохраняется там до просмотра.
- **Автозакрытие окна по «крестику»** прячет его в трей (приложение продолжает напоминать); настоящий выход — через меню в трее «Выход».
- **Аргумент `--tray`** — запуск сразу в трее (используется для автозагрузки).

## Шаблоны

| Шаблон | Режим | Когда | Дни |
|---|---|---|---|
| Каждый час (рабочая классика) | каждые 60 мин | 09:00–18:00 | Пн–Пт |
| Каждый час в :55 (08:00–17:00) | каждый час в :55 | 08:00–17:00 | Пн–Пт |
| Помодоро 25/5 | каждые 25 мин | 09:00–18:00 | Пн–Пт |
| Глаза 20-20-20 | каждые 20 мин | 09:00–19:00 | Пн–Пт |
| Разминка каждые полтора часа | каждые 90 мин | 10:00–17:00 | Пн–Пт |
| Обед в 13:00 | ежедневно в 13:00 | — | Пн–Вс |
| Вечернее чай/кофе в 16:00 | ежедневно в 16:00 | — | Пн–Пт |
| Отбой от экрана в 23:00 | ежедневно в 23:00 | — | Пн–Вс |

После выбора шаблон просто заполняет поля — всё можно докрутить вручную.

## Файлы приложения

- Настройки: `%APPDATA%\Perekur\settings.json` (при повреждении переименовывается в `settings.json.bak` и создаётся заново)
- Автозагрузка: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` → `Perekur`
