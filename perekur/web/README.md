Тот же «Перекур», но в браузере: сигнал в выбранное время, готовые шаблоны, дни недели, диапазон времени и уведомление в панели уведомлений Windows (Action Center) — без установки чего-либо.

## Быстрый старт

**Вариант 1 — просто открыть файл.** Двойной клик по `index.html`. Проект работает и так — расписание, звуки и даже загрузка своего звука (на время сессии). Не доступны только установка как приложение (PWA) и офлайн-режим Service Worker — им нужен HTTP(S).

**Вариант 2 — локальный сервер** (как в превью):
```bash
python3 -m http.server 8000   # или: npx serve
```
Откройте http://localhost:8000

**Вариант 3 — GitHub Pages.** Settings → Pages → Source: `Deploy from a branch`, ветка `arena/26447c4c-soft`, папка с сайтом `/perekur/web`… (Pages умеет только корень и `/docs`, поэтому для Pages скопируйте `web/` в `/docs/` или используйте GitHub Actions). После публикации сайт будет доступен по `https://visiontripin.github.io/soft/…`.

## Возможности

- 🧩 **8 готовых шаблонов** — как в десктоп-версии, включая «Каждый час в :55, 08:00–17:00»
- 🔔 **Три режима**: каждые N минут в диапазоне (сетка от начала диапазона), **каждый час в указанную минуту** (например, в :55 с 08:00 до 17:00) или ежедневно в выбранное время
- 📅 **Дни недели** (Пн–Вс-чипы) и **диапазон времени** (например, 09:00–18:00)
- 🔊 **10 синтезированных звуков** (Web Audio API) + прослушивание; загрузка своего файла (≤ 1,5 МБ; хранится в браузере, а если хранилище недоступно — работает на время сессии)
- 🪟 **Системные уведомления** через Notifications API (попадают в Action Center Windows 10/11) + системный звук, мигающий заголовок вкладки («🔔 Перекур!»), красный бейдж на favicon и полноэкранная карточка с кнопками «✓ Я сделал перекур» / «+5 минут»
- 💾 Настройки — в `localStorage`, переживают перезагрузку
- 📱 **PWA**: устанавливается как приложение (кнопка «⬇ Установить»), работает офлайн (Service Worker)
- 🌙 Тёмная тема — автоматически по `prefers-color-scheme`

## Отличия от десктоп-версии

| | Десктоп (`perekur/src`) | Веб (`perekur/web`) |
|---|---|---|
| Звуки | системные звуки Windows + `C:\Windows\Media` | синтез (Web Audio) + загруженный файл |
| Уведомление | Action Center (Windows) | уведомление браузера → Action Center |
| Работа в фоне | всегда (процесс + трей) | пока открыта вкладка (или установлено PWA) |
| Настройки | `%APPDATA%\Perekur\settings.json` | `localStorage` |
| Трей | да | мигающая вкладка + бейдж на иконке |

## Важное ограничение браузеров

Таймеры в **фоновых вкладках** замедляются браузером (Chrome — до 1 раза в минуту), поэтому сигнал может прийти с опозданием, пока вкладка «спит». Чтобы напоминания приходили вовремя: держите вкладку открытой и закрепите её (ПКМ → «Закрепить») или **установите Перекур как приложение** — установка появится после открытия сайта по HTTP(S) (кнопка «⬇ Установить»). При возвращении на вкладку пропущенный сигнал сработает сразу.

## Автотесты

Чистая логика расписания (`scheduler.js`) покрыта тестами на `node:test`:
```bash
cd perekur/web
node --test test/scheduler.test.mjs
```
Ожидается: `# pass 24`. 

> Если страница открыта двойным кликом по `index.html` (протокол `file://`), всё работает — вкладка просто не может считаться «установленным приложением».

## Файлы

```
web/
├─ index.html            # разметка
├─ styles.css            # стили (тёмная тема, адаптив)
├─ app.js                # состояние, DOM, таймер, уведомления
├─ scheduler.js          # чистая логика расписания (тестируема)
├─ sounds.js             # синтез звуков (Web Audio) + свой файл
├─ templates.js          # готовые шаблоны
├─ manifest.webmanifest  # PWA-манифест
├─ sw.js                 # Service Worker (офлайн + клик по уведомлению)
├─ icons/                # 192/512/apple-touch-icon
└─ test/scheduler.test.mjs
```
